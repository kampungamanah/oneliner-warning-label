# oneliner-warning-label

The safety warning label that should come printed on every human being.

`main.ts` writes the line to `/output/entry.txt`:

> WARNING: Says 'just one more episode' five times, then finishes the season. Keep away from streaming services.

## Run

    node main.ts

It writes the entry text to `$MAKEFUN_OUTPUT_DIR/entry.txt` when set, else `/output/entry.txt`.
